Transparencia metodológica
Score compuesto · Trazabilidad · Umbral de competencia mínima · Marco de referencia
▶
📐 Score compuesto
score = (precisión × 0.7) + (avance × 0.2) − (errores × 0.1)
Pondera desempeño técnico (70%), progresión en misiones (20%) y penaliza errores críticos (10%).
🔍 Trazabilidad de registros
ID = nombre + simulación + misión + intento
Cada registro es un evento independiente de aprendizaje — garantiza análisis longitudinal sin pérdida de datos.
📏 Umbral de competencia mínima (75%)
El 75% de precisión equivale a competencia clínica básica en RCP, coherente con estándares AHA 2025.
📖 Marco de referencia
Análisis primera vs. última simulación — modelo pre-test / post-test implícito. Datos en tiempo real vía Google Sheets.
Clasificación de riesgo
–
ALTA · <50% o >3 errores
–
MEDIA · 50–75% o ≥1 error
–
OK · >75% precisión
Criterios de clasificación pedagógica
Las alertas se generan con base en umbrales de desempeño que indican riesgo en la ejecución del protocolo BLS/AHA 2025, permitiendo intervención pedagógica oportuna antes de la siguiente simulación.

● ALTA Precisión <50% o más de 3 errores críticos — compromete la seguridad del paciente simulado.
● MEDIA Precisión entre 50–75% o con errores críticos ≥1 — por debajo del umbral de competencia mínima, requiere refuerzo dirigido.
● OK Precisión ≥75% — supera el umbral de competencia mínima, puede avanzar a escenarios más complejos.

// En tu Apps Script, dentro de doGet(e):
if (e.parameter.dashboard === '1') {
  const sheet = SpreadsheetApp.getActive()
    .getSheetByName('RCP HERO DATA');
  const rows  = sheet.getDataRange().getValues();
  const [headers, ...data] = rows;

  // Mapea cada fila a un objeto
  const records = data.map(r => ({
    nombre:    r[0],   // col A
    fecha:     r[1],   // col B (timestamp)
    mision:    r[2],   // col C (número 1-20)
    nivel:     r[3],   // col D (Fácil/Intermedio...)
    precision: Number(r[4]),  // col E
    errores:   Number(r[5]),  // col F
    insignias: Number(r[6]),  // col G
    sesion:    Number(r[7])   // col H
  }));

  return ContentService
    .createTextOutput(JSON.stringify({ records }))
    .setMimeType(ContentService.MimeType.JSON);
}
TRAZABILIDAD: Cada registro corresponde a un evento independiente identificado mediante ID único nombre + timestamp + misión + intento + índice — garantizando que múltiples participaciones del mismo estudiante se traten como eventos separados, sin pérdida de datos longitudinales.
